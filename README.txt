AlagaLink — Group Photo and Logo Update

UPLOAD THESE FILES TO THE ROOT OF YOUR GITHUB REPOSITORY:
- index.html
- styles.css
- script.js
- alagalink-logo.svg
- group-photo.jpg

HOW TO UPDATE:
1. Extract this ZIP on your Android tablet.
2. Open your AlagaLink GitHub repository.
3. Upload/replace index.html, styles.css, and script.js.
4. Upload alagalink-logo.svg and group-photo.jpg into the same ROOT folder.
5. Commit the changes. Keep the filenames exactly as shown.
6. Wait for GitHub Pages to publish, then refresh the site.

The two group-photo areas in the website now use group-photo.jpg. The photo is displayed with contain-fit so the full group and its banner remain visible. The header logo has been enlarged for better visibility.

The language switch is implemented in script.js and the website includes English and Filipino text for marked sections and the supported dynamic health-guide content. Review the published site in both languages before submission; some unmarked text may still need translation if new content is added later.

Educational prototype only. The tracker is browser-session demonstration data, not secure medical storage. The sample appointment form does not book a real consultation.
